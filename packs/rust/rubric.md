# Rust Pack Rubric

评分只看学习者证据是否解释了概念边界、约束和可迁移用法。不得把流利复述当作掌握；必须优先识别误解并引用证据原文。

## recall

能用自己的话说出术语含义、核心约束和至少一个关键边界。

## explain

能解释规则为什么存在，以及它排除哪些看似可行但实际错误的写法。

## apply

能在小代码片段中正确使用概念，并说明例子为何满足该概念的约束。

## analyze

能对比至少两个方案，识别至少一个 trade-off，并说明适用条件或失败模式。

## evaluate

能定位至少一个 bug、设计缺陷或误解，并解释它违反了哪条约束。

## create

能产出可编译或结构清晰的 API、数据结构或模块方案，并说明关键设计理由。

## transfer

能在不同于原示例的项目或领域上下文中正确应用同一结构，说明哪些部分保持不变、哪些部分需要调整。
