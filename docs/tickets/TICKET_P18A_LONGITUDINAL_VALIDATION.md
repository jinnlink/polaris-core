# P18A 真实纵向验证

状态：Queued；依赖 P12F 与外部 P12G Coursebook 桥接完成。

服务主命题：验证真懂。

## 范围

- 在用户真实学习库的备份副本上运行预登记分析：Global Profile 各维度、跨域冷启动预测、教学锚点、HMM/hazard、MRT/签名/摩擦和育种效果。
- 画像门使用 P16E 冻结阈值；跨域预测要求至少 3 Pack leave-one-pack-out，并报告 calibration/logloss/Brier 与纯行为/纯 BKT 基线。
- 干预只分析预登记 MRT 决策点；不以观察性相关替代因果效果。
- 每次运行持久化窗口、样本、特征版本、基线、候选指标、结论和失败原因；Trust UI 可查看。
- 通过门的对象按既有受控开关激活；失败/样本不足保持 `shadow/unfit`，不得修改 A 类门或补写数据。

## 禁区

- 不在生产库直接做破坏性分析，不上传原始回答或画像。
- 不因工程发布进度降低样本量、留出、概率或改善门槛。
- 不把模拟/单测结果算作真实纵向通过。

## 验收

- 预登记文件 hash、只读备份分析、时间泄漏检查、基线对拍、重复运行决定性和 Trust 展示测试。
- 至少完整执行一次真实库分析；允许结论为 skipped/rejected，但必须有真实输出和下一次条件。
- SPEC §6 基线、隐私审计、`doctor` 和 `git diff --check` 全绿。

## 回滚

关闭新激活的受控开关并回滚本票；保留验证运行审计，不删除失败结果。
