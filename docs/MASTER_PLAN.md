# Polaris Core (v2) — 提取内核 + 重构计划

## Context（为什么做这件事）

同一个学习系统构想，被实现了两次，两次都臃肿：

- **rust-mastery-lab**（Learned 引擎）：把"理解用户"硬写成 Rust 关键词路由（9 个写死的桶 + 写死的提示语），必然死板。
- **Polaris**：真实可跑（~14k 行 TS、P00–P28 完成），但：① 用 FSRS 把"短期不忘"当成"掌握"；② 校准/情感信号采集了却不回流；③ 概念图谱只在 roadmap；④ 表面积过大（CEFR/识屏/浏览器/MemOS/planner/OKR/考试模式），且深度绑死英语。

臃肿来自**野心的表面积**，不是代码烂。直接"重写"会第三次臃肿（第三系统陷阱）。
目标：**提取最小不变内核 → 把智能放进"LLM 对丰富状态推理" → 以"验证真懂"为主命题 → 把 FSRS 降级为调度输入之一、上面盖一个更聪明的多分量掌握度模型 → 用编译型高性能内核承载。**

## Thesis（一句话主命题）

**验证真懂 → 定位模糊 → 针对性补缺。**
Mastery 的定义从"短期不会忘"改成：**在足够深度上被证明的、校准过的、可溯源的理解。**

## Scope：keep / kill / build

**KEEP（从 Polaris 提取）**
- 证据账本 `evidence_items` + `op_log`（append-only、带来源、可溯源）。
- strict-citation 校验器（`apps/analysis/src/llm/codex_report.ts:48 validateCitations`）——evidence-bound 的硬保证。
- FSRS 遗忘曲线（`apps/web/src/lib/fsrs.ts`）——**仅作"何时复习"的调度输入**，不再等于掌握度。
- 四模式自适应思想（comfort/reinforce/explore/review，`coach/context/route.ts:657 pickTeachingStrategy`）。
- 本地优先 SQLite + 目标引擎概念（goals/dimensions/milestones，schema v9）。
- LLM 经 OpenAI-compatible endpoint 调用（已验证）。

**KILL（移出内核 → 降为插件/track）**
- CEFR 专有的一切（cefr_vocab/grammar、comfort-zone 的 level 覆盖率算法）。
- 识屏 sensor、浏览器扩展、MemOS、planner/budgets/OKR、考试模式、7 agent 角色文档、Next.js 耦合。

**BUILD（两边都没做、却本该是核心）**
1. 多分量掌握度模型（替代 `stability>=5`）。
2. 校准追踪（自信 vs 正确）。
3. 概念图谱（prerequisite / confusion_pair）。
4. 验证-教学闭环（主命题）。
5. AI→引擎 回写接缝。

## 更聪明的评分模型（替代 "stability>=5 = 掌握"）

每个 `(learner, concept)` 维护一个 **Mastery State 向量**，全部分量透明、可溯源：

| 分量 | 含义 | 更新方式 | 用途 |
|---|---|---|---|
| **R 保持度** | FSRS 式遗忘曲线 | 沿用 `fsrs.ts`，可后续按个人历史拟合参数 | **决定何时复习**（仅此） |
| **θ 潜在技能向量** | 学习者在 K 维共享抽象空间的位置（MIRT，**跨域共享**，详见"抽象引擎"节） | 每次 attempt 对数似然梯度小步更新；夜间巩固重校 | 预测未见概念、选难度(i+1)、迁移加速、"学什么最划算" |
| **p_known** | "真的会"的概率 | BKT 式（p_init/learn/slip/guess），由评分证据更新；欠观测概念用 θ·q 先验，按证据量 Kalman 式融合 | 判定掌握 |
| **C 校准** | 自信与正确的差 | Brier/ECE，按 `self_confidence` vs 实际 | **"你以为会其实不会"探测器** |
| **D 深度** | Bloom 深度 | LLM 评判：recall→explain→apply→transfer | 掌握需 D≥apply 且有迁移证据 |
| **w 证据权重** | 不同证据可信度 | 自由讲解/迁移 > 改写 > 完形 > 选择 > 点按 | 加权所有更新 |

**"掌握" = p_known 高 AND 深度≥apply AND 不过度自信 AND 保持度稳定。**
调度器只消费 R；"接下来教什么"消费 θ/D/C + 图谱。这直接回应"更智能的校度评分"，且不再把记得住=学会。

## 抽象引擎：三层知识表示（核心算法设计，替代"平面图谱+手写类比边"）

"人脑式高维抽象内联"的可构建版本 = 三种表示互补。
设计原则：**几何提议，结构裁决，潜因子承载迁移；LLM 供世界先验，个人数据供修正。**
根基先例：MIRT/Q-matrix（心理测量）、知识空间理论、Gentner 结构映射、互补学习系统（认知科学）、AFM/PFA（教育数据挖掘）。明确拒绝 DKT 类深度模型——n=1 数据量不配。

### 表示一：符号层 —— 类型化超图（可审计）
- 节点分层：L0 域概念（`rust:ownership`、`jp:は-topic`）；L1+ **抽象图式 schema**（`资源生命周期`、`话题-评述结构`）。
- 边类型：`prerequisite` / `confusion` / `component_of` / `instantiates`（概念→图式）/ `maps_to`（结构映射边，带对齐说明）。
- **图式不是手写本体**：由夜间巩固归纳产生；LLM 提议必须附 attempt 证据（strict-citation 延伸到图谱）；类比是**派生物**（同图式共属+结构对齐得分），不是手写原语。
- 结构映射得分：k-hop 邻域内带类型的近似图同态得分（贪心可算），几何层提议的候选必须过此裁决 + LLM 解释才能入图。

### 表示二：几何层 —— 嵌入空间（快速联想）
- 每个概念/图式存嵌入向量（embedding 模型）⊕ 图结构特征；HNSW 近邻索引（usearch/instant-distance）毫秒级检索跨域候选。
- **几何只提议，不裁决**——防表面相似污染图谱。

### 表示三：潜因子层 —— 共享潜在技能空间（迁移的数学核心）
- 模型：`P(答对 | 概念 c, 任务 t) = σ( a_c · (q_c · θ − b_c) − d_t )`
  - **θ ∈ R^K**（K=16~64）：学习者潜在技能向量，**跨所有域共享**——"高维抽象"的数学实体。
  - **q_c ∈ R^K**：概念载荷（Q-matrix 行），LLM 按图式先验初始化、数据在线修正。
  - b_c 概念难度；d_t 任务形式难度（自由讲解>改写>完形>选择）。
- **迁移自动涌现**：新概念装入时经嵌入近邻图式继承 q 先验；θ 在重叠维度已高 ⇒ 预测掌握度天生非零 ⇒ "迁移评估"=带置信度的真实预测。
- **迁移梯度**：练 X 对目标 Y 的价值 = ∂(Y 相关概念预测掌握)/∂(练习X)，调度器直接消费，回答"现在学什么最划算"。
- 与观测层关系：BKT/校准按直接证据更新；MIRT 供欠观测概念先验；按证据量 Kalman 式融合（证据少信先验、证据多信观测）。

### 双过程学习循环（仿海马快/皮层慢——抽象如何长出来）
- **快通路**（Tier 0，每次 attempt，微秒级）：概念级 BKT/校准更新 + θ 对数似然梯度小步上升（步长帽）。
- **慢通路**（Tier 1，夜间"睡眠巩固"）：
  1. 重拟合有足够数据概念的 q 行（正则化逻辑回归 vs θ 历史）；
  2. 聚类预测残差 → 发现"现有维度解释不了的共同失败模式" → 提议新图式/新潜在维度；
  3. LLM 给新图式命名+描述（必须引用具体 attempt 证据）；
  4. 合并 q 相关性过阈值的图式（防维度碎片化）。
- **巩固硬验收**：每次巩固必须提升留出集（hold-out attempts）预测准确率，否则自动回滚。抽象用预测力证明自己，不靠感觉。

### 诚实边界
- n=1 稀疏 ⇒ K 小、先验强、可辨识性护栏（正则化+维度上限+合并规则）。数据少时≈LLM 先验驱动，数据多时个人化锐化——优雅降级，即"多重混合"。
- 不承诺无先验涌现脑级抽象；承诺 **LLM 世界先验 × 个人数据几何 × 可审计符号层** 的可构建逼近。

### 性能承诺（Rust 内核）
- K≤64 线性代数（θ 更新、q·θ 预测）纳秒~微秒级，ndarray/原生 vec；HNSW 毫秒级；SQLite 存储、嵌入 BLOB。
- 唯一重活=夜间巩固（重拟合+聚类+LLM），完全离线——延迟铁律不破。

## 验证-教学闭环（主命题 = walking skeleton）

单一端到端闭环，**单 track、零集成**：

1. ingest 一条真实证据（你的讲解/尝试）。
2. LLM 评分（evidence-bound + strict-citation）：正确性、深度、命中哪个概念、触发哪种误解、自信-正确差。
3. 引擎更新掌握度向量 + 图谱。
4. 引擎**按缺口**（不是模板）选下一步：最模糊/最不校准的概念，在正确深度。
5. LLM 在 i+1 难度生成针对性微任务（用图谱做脚手架）。
6. 你做 → 回写（AI→引擎 ingestion 工具）。循环。

**判据：这个闭环在单 track 上"活、不死板"，内核就站住了。**

## 技术栈（性能 + 诚实权衡）

- **诚实说**：内核计算是微秒级；真正延迟在 LLM（~20s 超时）。**裸速度不是上编译型的理由。**
- **上 Rust 内核的真实收益**：单一本地优先可嵌入 daemon；类型安全的掌握度/图谱状态（正确性）；低内存常驻 ambient 进程；Tauri 桌面壳（即 Learned 里设想的 "Aura" 伴随）；**与你的 Rust 学习对齐——这里双目的是一致的，因为内核就是产品本身。**
- **推荐**：**Rust 内核 crate**（掌握度模型 + 概念图谱 + 调度器 + 证据库 + LLM 客户端），对外经 (a) axum HTTP 给瘦 Web UI、(b) Tauri 给桌面。SQLite 用 `rusqlite`（复用 Polaris schema 形状）或 `redb`。LLM 用 `reqwest` 打 OpenAI-compatible endpoint。
- **UI 复用**：移植 Polaris 的 React dashboard 做瘦前端，**UI 不进 Rust**。
- **护栏**：只有内核进 Rust；集成（ingest 适配器、sensor）是独立进程/插件。

## AI 分工矩阵 + 延迟预算（用户硬要求：不能等太久）

三层执行者，**同步路径上永远没有 LLM**：

| 层 | 是谁 | 干什么 | 延迟 |
|---|---|---|---|
| **Tier 0 引擎计算** | Rust，无 LLM | 调度、掌握度更新、校准计算、图谱查询、按缺口选题 | **<10ms 同步**。"打开就要看到"的一切只走这层 |
| **Tier 1 内置后台 AI** | 引擎自己调的 LLM（OpenAI-compatible，可配置） | evidence-bound 评分、证据结构化解析、日结/周报/洞察提炼、图谱边提议 | **异步**，用户从不阻塞等它 |
| **Tier 2 外部导师** | Codex/Claude Code/IDE AI，经 MCP | 教学对话、讲解、苏格拉底追问、深度诊断（拿引擎状态做） | 用户本来就在等对话打字，无额外感知 |

**定位铁律**：Tier 1 是"引擎的后台雇员"，不是"用户的对话对象"；对话对象默认是 Tier 2 外部导师（内置聊天仅可选面板）。"高端推理"（深度诊断、策略复盘、高维分析）默认 Tier 2 实时做、或 Tier 1 夜间异步做，**绝不放在同步路径**。

**效率机制**（每条都是 GPT 必须实现的硬规则）：
1. **乐观更新**：提交证据后，立即按自评+启发式预落账（标记 `provisional`），Tier 1 评分回来后修正掌握度并在 UI 标记变化。用户零等待。
2. **模型分级路由**：`POLARIS_LLM_FAST`（结构化提取、轻解析）/ `POLARIS_LLM_STRONG`（深度评分、周报）两档可配置，沿用 Polaris base_url/model 模式。
3. **后台批处理**：总结/洞察/图谱提议在空闲/夜间跑，结果次日呈现。
4. **全任务降级**（继承 Polaris graceful degradation）：LLM 不可用 → 启发式落账+排队重试，绝不崩、绝不假装没依赖 AI。
5. **常驻小窗秒开保证**：小窗内容 100% 来自 Tier 0 缓存状态。

## Domain Pack：多域插拔（日语/英语/任意技能）

内核**域无关**（concepts/edges/mastery/evidence 不含任何域逻辑）。一个域 = 一个**声明式 pack 目录**（形状提取自 rust-mastery-lab 已验证的 `domain/*.toml`）：

```
packs/<domain>/
  pack.toml           # 元信息：名称、scope_types、版本
  concepts.toml       # 概念种子 + 初始 prerequisite 边
  misconceptions.toml # 常见误解库
  rubric.md           # 评分提示词模板（该域的深度判定标准+示例）
  ingest.toml         # 证据类型映射（如 cargo test 输出→attempt）
  moves.toml          # 领域专用教法模板（如编程的 PRIMM/Parsons/解释diff，语言的 shadowing/句子挖掘）
```

- **装新域 = 放一个 pack 目录**，零代码改动；`polaris pack validate <dir>` 验收。
- 这也是 Polaris Core 对外部课程开放的**课程接入协议**：外部课程不是把课件直接塞进系统，而是实现一组稳定的 pack 文件、证据映射、评分标准和教学 move；内核只消费协议，不理解具体学科。
- pack 纯声明式不含代码；域专用 ingest 适配器（如识屏、浏览器扩展）是独立进程，经 HTTP/MCP 接入。
- 概念种子可由 LLM 生成初稿（如日语 JLPT N5-N1），用户/引擎确认后入库。
- 英语 pack 从 Polaris CEFR 表直接导出——既是迁移路径也是插拔验收。

## 跨域迁移层：总内联加速（抽象引擎 + Global Learner Profile）

迁移的**主载体是抽象引擎的共享 θ 空间**（见上节）——第一性机制，不靠手写边。Global Profile 补充潜因子之外的跨域资产：

1. **校准画像**：跨域过度自信/不自信倾向 → 新域冷启动时初始化 C 分量先验。
2. **误解风格**：你犯错的模式（过度泛化规则/忽略边界/符号混淆）→ 注入评分提示词："该学习者易犯 X，重点核查"。
3. **策略效果库**：哪种练习类型/教法对你有效（Polaris `strategy_trial/backtest` 雏形提升为全局资产）→ 新域开局直接用对你最有效的教法。
4. **节奏特征**：最佳 session 长度、频次、放弃前兆 → 调度参数先验。

**新域冷启动流程**：装 pack → 概念嵌入 → 近邻图式继承 q 先验 → θ·q 输出**预测掌握度地图**（哪些大概率秒懂/哪些必须细学，带置信度）→ 结构映射生成教学锚点（"你已会 X，这个像 X、差在 Y"）→ 带锚点的初始路径。

## 心智动力学引擎（Learner Dynamics Engine——第三支柱）

知识状态（抽象引擎）回答"你会什么"；本引擎回答"你此刻是谁、什么对你有效"。
总原则：**先验来自科学文献，后验来自你的数据；一切构念必须在留出集上证明预测力，否则自动降级为"未验证"。**

### 反伪科学红线（发刊级的第一要求）
- 禁用：学习风格类型（视觉/听觉型，Pashler et al. 2008 证伪）、MBTI、一切不可证伪的"类型"标签。
- 允许的构念双重门槛：有效度文献支撑 + 在本系统内可被行为数据证伪。

### 三时间尺度分层（层级贝叶斯）
1. **特质层（月尺度，慢先验，永远带不确定度）**：Big Five 中对学习坚持有预测力的面向（尽责性、神经质/焦虑易感、开放性）、目标取向（掌握型 vs 表现型，Dweck/成就目标理论）、归因风格（习得性无助，Seligman）、自我效能（Bandura）。估计：行为数据为主 + 偶发微问卷（验证过的量表条目拆成 EMA 式单题，绝不一次性长问卷）。
2. **状态层（分钟尺度，快滤波）**：离散 HMM {心流/投入、生产性困惑、挫败、无聊、焦虑、疲劳}——构念取自 D'Mello & Graesser 学习情感动力学。**"生产性困惑"是关键状态**：困惑在解决前是学习金矿，超时未解才转挫败（最优困惑区）。发射=行为观测；转移矩阵受特质层调制。前向滤波 O(S²)，微秒级，Tier 0。
3. **事件层（每 attempt）**：已有观测（latency/hints/自信/分数）。

### 行为观测字典（Phase 1 第一天就必须全量记录）
latency 分布与突变、hint 频率与升级模式、删改重写次数、放弃（任务/会话/话题三级）、会话间隔与时段、连续错误后的下一动作（重试/换题/退出）、自信-成绩剪刀差、gaming 检测（快速乱猜/刷提示，Baker 系检测器）。

### 放弃与挫败预测（"比你更了解你"的可验证形式）
- **生存分析 hazard 模型**：t 时刻放弃（会话/话题/目标三级）的瞬时风险，协变量=状态+特质+知识状态+近期轨迹。
- **挫败前瞻**：状态滤波+转移模型 → 未来 10 分钟挫败概率，预警给教学策略。
- **镜像报告（周）**：只说可验证的话——"你周二晚的放弃风险是周六上午的 3.2 倍""连续 2 次 hint 后你 71% 会退出；此时切换工作样例可把留存提到 84%（已验证 n=23 次干预）"。每条带证据 id 与置信度。说不出证据的话不许进报告。

### 因果干预引擎（"你吃哪一套"的科学化——发刊级方法论核心）
- 方法论 = **JITAI + 微随机化试验（MRT，Susan Murphy/移动健康方法论）**：在策略允许窗口内对教学 move 轻度随机化，估计**个体异质处理效应** τ(move | 状态, 特质, 知识)——是因果不是相关。
- 文献效应量作 Bayesian 先验，个人后验经 MRT 更新——**先验来自科学，后验来自你**。Thompson 采样在 τ 后验上选 move。
- 由此整个系统成为**持续运行的 N-of-1 实验平台**（单被试实验设计 + 预登记式微随机化审计日志 + 留出预测验证）——这正是 Nature Human Behaviour 级的方法栈。

### 难度与负荷控制（神经科学锚点）
- **85% 规则**（Wilson et al. 2019, Nature Communications）：最优学习率在 ~85% 成功率附近 → 调度器把任务难度调到预测成功率 0.80–0.90（困难但可赢）。
- 认知负荷理论（Sweller）：从 latency/错误模式估负荷；超载降内在负荷（拆步），永远压低外在负荷。
- 预测误差驱动学习（多巴胺 RPE）：适度 errorful generation + 立即反馈（Metcalfe）——惊讶增强记忆。
- 好奇缺口引发（Gruber：好奇状态提升海马编码）：新概念前置"你猜会怎样"问题。
- 状态调制总则：挫败态→降难度+工作样例+小赢；**生产性困惑→不救**，守住最优困惑区到时限；无聊→难度↑或换 move；心流→不打断。

### 灵活性保证（用户硬要求）
- 策略是概率性的（Thompson 采样自带探索），不是 if-else 规则表。
- 脚手架随 p_known **连续衰减**（专长反转效应，Kalyuga：工作样例帮新手、害熟手）——没有写死的"模式"。
- 模型对用户透明可质疑：镜像报告附证据，用户可标"不准"，该反馈本身成为校正数据。
- 诚实边界：状态构念非临床诊断（"焦虑态"≠焦虑症）；自报告稀疏时不确定度如实放大。

## 原创理论层：五个框架（学术贡献声明，附诚实先行工作对照）

五个框架**全部由已有支柱的原语组装而成**（签名=掌握度向量×MRT；相图=向量空间分区；摩擦=85%规则×hazard 统一；误解语法=残差管线×LLM 溯因升级；育种=MRT×move库的生成式扩展）——是深化不是偏离。每个框架带验证门，不过门就只是假设。

**个人化铁律（因人制宜的结构化保证）**：群体先验（文献效应量、pack 种子、相判据阈值）只作初始化；一切运行参数——签名、φ\*、相阈值、Q、θ、G_u、move 效应——都必须有按人后验的更新路径。系统的默认形态就是"对你"的版本，不存在不个人化的运行模式。

**开放理论层（AI 发现新方法/新理论的正式通道）**：F5 育种发现**新方法**；夜间巩固可提议**新潜在维度、新图式、新相、新状态构念与新的个人规律**（经镜像报告呈现）——理论对象集本身是数据驱动可扩展的，一律过留出验证门。"AI 可能发现全新的方法甚至理论"由此是系统的常规产出，不是偶然。

### F1 教法状态向量签名分类法（Method Signature Space）
- **定义**：每个教法 m 的签名 `sig(m | 状态,特质) = E[Δ(R, θ, p_known, C, D, edges) | 施加 m]`——方法不按表面形式分类，按"实测推动学习者状态向量的方向"分类。文献效应量为先验，个体后验由 MRT 估计。
- **选法法则**：`m* = argmax ⟨缺口向量(c,t), sig(m)⟩ − cost(m)`——哪个分量落后，就选签名指向该方向的方法（gap-driven）。
- **先行工作（诚实）**：Koedinger KLI 框架、AFM/教学因子分析有"方法×知识类型匹配"思想。**真正新的**：把方法形式化为多分量状态空间上的算子向量、纳入校准 C 与深度 D 分量、n=1 因果估计、内积选法。判定：部分原创。
- **验证门**：签名引导的选法在留出期的学习增益必须优于"固定最优方法"基线。

### F2 知识相图（Knowledge Phase Diagram）
- **定义**：每条知识按完整向量落入离散"相"，相由可观测量操作性定义：
  **幻影态**（自信高/实测低，C 缺口大）→ 费曼/超校正修复；**脆弱态**（答对但 D 停在 recall/explain）；**惰性态**（会但真实情境检索不出——inert knowledge）；**僵硬态**（仅原情境会，无迁移）；**活跃态**（可迁移）；**自动化态**（低 latency 低负荷）。
- **教学=相变工程**：每个 move 是特定相变的算子，相变转移概率从数据估计（Markov 算子）。UI 的状态镜子直接显示相图分布，替代百分比进度条。
- **先行工作（诚实）**：Bjork 双强度理论（存储强度×提取强度，2 维）是最近先驱；inert knowledge（Whitehead 1929）、SOLO 分类。**真正新的**：扩到 ≥5 维可观测（加校准/深度/latency/迁移）、离散相+操作性判据、幻影态的校准操作化、相变算子可测。判定：Bjork 模型的实质扩展，部分原创。
- **验证门**：相分类对下次表现的预测必须优于单用 p_known。

### F3 个人摩擦响应曲线（Personal Friction Response Curve）
- **定义**：把合意困难(Bjork)、生产性失败(Kapur)、最优困惑区(D'Mello)、85%规则(Wilson) 统一为单一控制量 **摩擦 φ**（难度差距×僵局时长×提示延迟×去脚手架度的复合），对每个学习者×状态拟合两条曲线：学习增益 g(φ) 与放弃风险 h(φ)，**个人最优摩擦 φ\* = argmax [g(φ) − λ·h(φ)]**。
- 系统实时把任务摩擦调到 φ\*（替代全局 85% 固定值）；φ\* 随状态移动（挫败态左移、心流态右移）。
- **先行工作（诚实）**：85%规则（单维错误率）、ZPD（定性）、心流通道（定性）。**真正新的**：复合可控变量 + 增益/风险联合拟合 + 个体×状态最优点的闭环控制律。判定：操作化层面基本原创。
- **验证门**：控制 φ→φ\* 的留存/单位时间增益必须优于固定 85% 目标。

### F4 跨域个人误解语法（Personal Error Grammar）
- **定义**：经残差聚类+LLM 溯因，自动归纳学习者**跨领域反复出现的抽象错误生成规则**（过度泛化/边界盲区/符号-所指混淆/因果方向颠倒/流畅性错觉…），形成个人误解语法 G_u；G_u 可**前瞻预测**新领域中将犯的错。
- **三处消费**：评分器先验（"该学习者易犯 X，重点核查"）、反驳式教学的靶点、AI 学生 move 的剧本（见纲要家族六）。
- **先行工作（诚实）**：BUGGY/修复理论（VanLehn）、mal-rules、领域误解库（如物理 FCI）——全是**领域级静态目录**。**真正新的**：个人级×跨域×自动归纳×预测验证。判定：在该交叉点上原创。
- **验证门**：G_u 对未来错误的前瞻预测精度（precision）有门槛，预测不中的规则自动降权。

### F5 教法育种引擎（Pedagogy Breeding）
- **定义**：教法不止从固定库选择，系统**生成并检验新方法**：把已验证方法分解为机制原语 P={检索,生成,对比,间隔,具体化,自解释,类比,反馈时机,自信下注,变异}，LLM 在约束下组合候选微方法（如"延迟反馈的对比式检索"），**预登记 MRT 测试**，τ 后验以 >0.8 概率优于在位者才准入库。
- **先行工作（诚实）**：Min Chi & VanLehn 的 RL 教学策略（在固定动作集中优化选择）、hint factory（Stamper & Barnes）、ASSISTments 平台级 A/B。**真正新的**：生成式组合出**新动作** + n=1 因果准入 + 预登记纪律。判定：组合层面原创。
- **验证门**：预登记强制；准入后持续监控，效应衰减自动退役。Phase 5+ 才启动（需 MRT 成熟）。

## 形式化补遗（GPT 实现依据）

### A. 关联评分与四空间
概念关联定义在四个耦合空间，强联想=多通道一致：
语义 E⊂R^d（嵌入，cos_E"听起来像"）/ 技能 Q⊂R^K（cos_Q"同一块心智肌肉"）/ 残差空间（coh(a,b)=corr(残差a,残差b)，个人特有"在你身上一起塌"）/ 结构 G（struct=k-hop 类型化子图贪心对齐得分）。

`assoc(a,b) = α·cos_E + β·cos_Q + γ·struct + δ·coh`（初始 α=.15 β=.35 γ=.25 δ=.25，可调）

**发现优先级（洞察=语义远而深层近）**：`discover(a,b) = (β·cos_Q + γ·struct + δ·coh) · (1 − cos_E)`
——语义层看不见、行为+结构通道却一致的配对优先送巩固审查。这是"高维联系"的机器化定义。

### B. 抽象发现管线（夜间巩固三段式）
① 统计提议：残差矩阵 Z（观测−θ·q 预测）稀疏因子分解/聚类 → 共塌簇=候选新维度；② LLM 溯因：命名+描述+必须引 attempt 证据（strict-citation）；③ 预测验证：K+1 重拟合，留出集 logloss 必须改善否则丢弃。**LLM 是假设生成器，统计是过滤器。**

### C. 调度效用函数（五项读取）
`U(c) = w_R·(1−R) + w_cal·校准缺口 + w_mis·误解激活 + w_tr·迁移梯度(c→目标) + w_beh·行为契合`，前置未达标乘衰减。
五项读取：①间隔(FSRS R)；②上次/这次对比(Δscore/Δlatency/hints/自信剪刀差)；③易错(误解激活+lapses+confusion边)；④行为特征(时段效应/放弃前兆)；⑤高维抽象(θ·q 预测 vs 观测残差——区分"不会"与"局部炸点")。全部 Tier 0。

### D. 教学方法库 v2（文献锚定 + 因果个人化）
每个 move 携带：机制（认知/神经）、文献先验效应量、前置条件（状态×特质×知识）、**禁忌**。先验来自科学，后验来自 MRT（见心智动力学引擎）。

| Move | 机制/出处 | 先验效应 | 前置/禁忌 |
|---|---|---|---|
| 检索练习 | 测试效应，Karpicke & Roediger (Science 2008) | d≈0.5–0.8 | R 衰减时；忌挫败态 |
| 间隔+扩张复习 | 巩固理论，Cepeda/Bjork | d≈0.4–0.9 | 由 R 层执行 |
| 交错练习 | 辨别学习，Rohrer | d≈0.4 | confusion 边活跃/图式级训练 |
| 自解释提示 | Chi；ICAP 的 C 级 | d≈0.5 | explain→apply 坎 |
| 工作样例→渐隐 | 认知负荷，Renkl；**专长反转**(Kalyuga) | 新手 d≈0.6 | p_known 高时**禁用**（反转伤害） |
| 生产性失败 | Kapur：先挣扎后授课，深度↑ | d≈0.4–0.6 | 需自我效能中高+时间充裕；忌焦虑态 |
| 反驳式对照 | 概念变化理论，refutation text | d≈0.4 | 误解激活+过度自信 |
| 类比编码 | Gentner：双案例对比>单案例 | d≈0.5 | 图式近邻已掌握 |
| 预测试/好奇缺口 | pretesting effect；Gruber 好奇-海马 | d≈0.3–0.5 | 新概念引入前 |
| 苏格拉底探查 | impasse-driven learning, VanLehn | - | recall→explain；校准正常 |
| 边界探测 | 迁移测试 | - | 自称掌握待验证 |

总则：ICAP 框架（Chi）——交互>建构>主动>被动，生成任务尽量上移；难度目标=预测成功率 0.80–0.90（85% 规则）。
**引擎按（状态×特质×知识）选 move（Tier 0 确定性+MRT 探索），LLM 执行 move（创造性）**；MCP 下发结构化教学指令（focus/move/target_misconception/do/don't/anchor）。
完整广度见《教学法纲要 v3》节（八大家族）；领域专用模板入 pack 的 moves.toml；方法如何被选取由《原创理论层》F1 签名×F2 相图×F3 摩擦曲线决定。

### E. 元数据原则与核心表
一切派生知识带 `provenance + evidence_ids + 版本`（strict-citation 延伸到知识本身）。核心表：
`concepts(id,pack,kind,embedding BLOB,q BLOB[f32;K],b,…)` / `schemas(id,name,born_from,evidence_ids,status{候选|已验证|已合并},validation_report)` / `edges(src,dst,type,weight,alignment_json,provenance,evidence_ids)` / `attempts(…,latency_ms,self_confidence,provisional,grader_json)` / `theta(vec,version)+theta_history（可回放）` / `residual_stats` / `consolidation_runs(proposals,holdout_delta,accepted|rolled_back)` / `moves_effects(move,context_hash,bandit参数)`。

## § 认知科学锚点（Cognitive Science Anchors）

**设计原则：每个引擎特性必须溯源到至少一条经验验证的认知科学原理。**

完整映射表见 `docs/COGNITIVE_SCIENCE_ANCHORS.md`，该文件记录所有已实现和计划中特性对应的科学原理、关键文献和引擎模块映射。

规则：
1. **新特性提案必须引用至少一条认知科学原理**（附关键文献），或补充新原理到锚点文件。
2. **无科学锚点的特性标记为"假设"**，须过留出验证门（DATA_MODEL §10 A 类门槛）才能进入默认行为。未过门的假设不得进产品话术。
3. **被证伪的原理**（如学习风格类型，Pashler 2008）列入反伪科学红线（SPEC §3），禁止以任何形式进入系统。
4. **先验来自科学，后验来自你的数据**——群体文献效应量初始化参数，个人行为数据经事件溯源修正。系统是 N-of-1 实验平台，不是静态教科书翻译。

此原则与"验证门"铁律互补：验证门确保产物过预测力检验，科学锚点确保起点有理论基础。两者共同防止系统退化为无根据的启发式堆叠。

## 承重架构：引擎优先 · 多前门 · AI 无关（用户硬要求）

**绝不把学习绑死在 app 内置 AI 里。** 用户日常在 Codex / IDE / 多种 AI 工具间流动；学习必须能用手边任意 AI 工具进行，引擎在背后记录与判断。内置 AI 仅为可选便利。此架构与两个旧项目已有的 MCP 设计一致（rust-mastery-lab 的 labctl MCP、Polaris 的 28 工具 MCP + VSCode 扩展）——是提取、非发明。

**polaris-core 引擎**独占：状态 + 验证-教学闭环逻辑 + evidence-bound 评分。对外三个门：

1. **MCP server（主入口）**：Codex/Claude Code/IDE AI/Cursor 任意驱动——读掌握度状态、取按缺口生成的下一题、提交讲解/尝试、拿评分、回写证据。**你现有 AI 工具就是导师界面。**
2. **HTTP API**：给常驻伴随 UI 及其他客户端。
3. **内置 LLM（可选）**：伴随窗口可直调 LLM（沿用 Polaris `POLARIS_LLM_BASE_URL` 模式）。可选，非脊椎。

**评分一致性铁律**：无论在外部工具还是内置窗口学习，**引擎永远自己跑一遍 evidence-bound 评分**，掌握度口径统一；外部 AI 的判断作为附加证据被 ingest（strict-citation 校验），**不能直接覆盖引擎掌握度**。

## 前端形态：常驻+可展开，状态镜子为主（非僵硬）

- **承载**：Tauri 常驻小窗 + 可展开全屏工作区（已定）。
- **主角是状态镜子**，不是聊天框（因对话可发生在外部工具）：
  - 活的知识地图（会/模糊/未学）、模糊点、校准缺口（"你以为会其实不会"）。
  - 下一步动作（按缺口算出）+ 证据捕获（捕获你在任意工具产生的学习证据）。
  - 会话编排：串起一次闭环，无论用内置 AI 还是 Codex。
  - 内置聊天是**其中一个可切入面板**，不是整个应用。
- **反向约束内核 API**：暴露"丰富状态 + LLM 现生成内容"，而非固定 widget 数据。前端 Phase 4 落地，形态现在定调。
- 待细化：状态镜子的"活着呈现"具体视觉；证据捕获的具体手势。
