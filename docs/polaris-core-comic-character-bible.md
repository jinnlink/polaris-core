# Polaris Core 漫画角色与视觉设定

> 本文服务于自用漫画版本。系统事实见 `docs/polaris-core-comic-system-brief.md`；分镜脚本见 `docs/polaris-core-comic-script-v0.md`。

## 1. 自用版权约定

本项目当前定位为个人自用，不商用、不公开发行。因此自用版可以直接使用哆啦A梦作为伙伴角色。

如果未来要公开发布、商用、投稿、做宣传材料或上传到公开视频平台，应把哆啦A梦替换为原创角色，例如“蓝色口袋导师”。替换时保留角色功能，不保留受保护的外观识别特征。

## 2. Mona 的核心定位

Mona 是主角，不是吉祥物。

她的定位是：

- 系统探查员；
- 知识城的掌灯研究员；
- 读者问题的代言人；
- 把复杂结构一点点照亮的人。

她负责观察、怀疑、提问、推理、总结。她不是被动听讲的人，而是每一章里真正完成理解动作的人。

## 3. Mona 视觉基准

需要保留的关键特征：

- 白发，发尾轻盈，带透明感；
- 蓝紫色部分不是头发，而是透明渐变光幕、帽檐、星云或粒子层；
- 一只眼是金色实眼，另一只眼带未完成线稿感；
- 星形发饰和细金色挂饰；
- 深蓝星图斗篷，带星座线、光点和透明边缘；
- 白色内裙，低饱和、干净、轻；
- 手提暖金灯笼，作为“照亮证据和结构”的核心道具；
- 周围漂浮方块光效、星点、蓝色数据粒子；
- 身体局部保留线稿感，随理解推进逐步上色。

不要把 Mona 画成：

- 低龄幼教角色；
- 只负责卖萌的陪衬；
- 传统魔法少女变身模板；
- 过度战斗化的动作主角；
- 表情夸张但没有判断力的吐槽角色。

## 4. Mona 的成长弧

Mona 的视觉变化对应理解过程。

| 阶段 | 状态 | 视觉变化 |
|---|---|---|
| 入城前 | 以为“记住就是懂” | 身体大半是黑白线稿，灯笼微弱 |
| 证据法庭 | 发现评分需要证据 | 灯笼第一次稳定发亮 |
| 校准镜 | 承认“以为会”的落差 | 线稿裂纹收束，手臂上色 |
| 图谱诊断 | 看见概念关系 | 斗篷星线变清晰 |
| MIRT 星图 | 理解迁移 | 光幕展开成星云坐标 |
| 夜间巩固 | 理解系统的克制 | 灯笼从亮变稳，不再闪烁 |
| 尾声 | 回到主命题 | 线稿不完全消失，而是成为可见的“未完成空间” |

建议不要让 Mona 在结尾完全失去线稿感。保留少量线稿，表示学习永远未完成，系统仍在持续验证和补缺。

## 5. Mona 的语言风格

Mona 的台词要短、准、有判断力。

适合她的语气：

- “背下来，就算懂了吗？”
- “这不是分数，这是证据的影子。”
- “原来问题不在高塔，在地基。”
- “预测可以带路，但不能替我证明。”
- “学习不是把线稿涂满，而是知道哪里还空着。”

不适合她的语气：

- 长篇解释算法；
- 频繁惊叫；
- 只负责“哇，好厉害”；
- 过度撒娇；
- 用很幼稚的口头禅。

## 6. 哆啦A梦的角色功能

自用版可以直接使用哆啦A梦。

他的核心功能不是抢主线，而是把抽象机制变成可视化道具：

- FSRS：记忆保质期贴纸；
- Domain Pack：标准打包布；
- strict-citation：证据荧光笔；
- grade queue：排队保险箱；
- Event Sourcing：事件放映机；
- calibration：真实之镜；
- prerequisite：透视望远镜；
- confusion edge：原形毕露手电筒；
- MIRT：潜能力雷达仪；
- BKT-MIRT 融合：动态平衡天平；
- 参数登记处：A/B/C 参数抽屉；
- MCP：外部导师通行证。

他的台词可以轻巧，但要让位给 Mona 的发现。

## 7. Mona 与哆啦A梦的关系

两人的关系不是“老师给学生上课”，而是“发现者和工具箱协作”。

- Mona 是主光源；
- 哆啦A梦是道具出口；
- Polaris Core 是被照亮的城市本体；
- 外部导师是通过门进入的讲解者；
- 证据法官、管理员、门卫等角色代表系统模块。

典型节奏：

1. Mona 发现矛盾或提出问题；
2. 哆啦A梦拿出道具；
3. 系统机制被视觉化；
4. Mona 做出判断或提交证据；
5. Polaris Core 给出可审计反馈；
6. Mona 用一句话总结本页信息锚点。

## 9. 统一画风提示词

后续生成图像时可使用以下方向：

```text
delicate anime illustration, luminous star map cloak, white-haired young researcher, golden lantern, transparent blue-violet light veil, constellation lines, floating square particles, clean futuristic learning engine city, elegant comic panel composition, warm gold and deep indigo contrast, refined and intelligent expression, partially unfinished sketch lines, high detail, soft glow, not childish
```

负向方向：

```text
low age preschool style, over-chibi, chaotic UI, generic fantasy battle, excessive comedy face, muddy colors, text-heavy poster, random symbols, weak evidence/citation visuals
```

## 10. 对外替换方案

如果未来需要去版权化，哆啦A梦可替换为原创“蓝色口袋导师”：

- 体型圆润但不直接复刻；
- 有一个发光工具口袋；
- 颜色以蓝、白、暖金为主；
- 角色功能仍是道具化解释；
- 不使用哆啦A梦标志性脸型、铃铛、四次元口袋外观和专有道具名。

这样可以保留自用版的阅读爽感，也为未来公开版留出退路。
